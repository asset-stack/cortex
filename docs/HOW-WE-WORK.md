# How we work in Cortex

A short note for the team: who owns a task, what comes first, and where client work goes.

## Every task has one owner
- The **Owner** column says who is answerable for the task. One person, never a group.
- Need help from someone? Keep the owner and write `@Name` in an update on the task. They see it in My Work →
  **Mentions**.
- Handing a task over? Change the Owner. It shows as **New · from you** in their Priorities for two days.

## Priority says when
| Priority | Means |
|---|---|
| **Urgent** | Today. Drop other work. One Urgent task at a time. |
| **High** | This week |
| **Medium** | This month |
| **Low** | When free |

Anyone can set the owner and the priority. If two things feel Urgent, ask an admin which one is.

## Start the day in My Work
1. **Today**: your to-dos for the day.
2. **Priorities**: every open task you own (and any still shared, until one owner is picked), Urgent first. Work from
   the top.
3. Keep at most **2 tasks In progress**. Finish or pause one before starting another.
4. Stuck? Set the status to **Stuck** and say why in an update. On a team board, an admin sees it in Needs attention.

## Where work goes
- **Projects**: business-as-usual work on the team boards. Your own page is for personal notes.
- **Marketing**: posts, campaigns and events.
- **Clients → Demos / Previews**: demos and design updates for a client. Set the **Client** so the task shows in that
  client's page.
